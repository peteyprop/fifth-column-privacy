Privacy Policy — Fifth Column

Last updated: 25 September 2026

Fifth Column ("the app") is developed by Peter McCormack ("we", "us"). This policy explains what the app collects, why, and what happens to it.

What we collect

The app records gameplay events so we can see how the game is actually played: which characters get picked, how far a game gets before it ends, how long a game takes, and whether a tutorial lesson was passed. Specifically:

  • A random identifier generated on your device when you first install the app. It is not your name, email or any account — it is a random string used only to group your own gameplay rows together over time (for example, to measure whether players come back the next day).
  • Gameplay events: which character and role you played, the game mode and table size, how the game ended (won, lost, or abandoned) and why, how many turns it lasted, and how long it took.
  • Tutorial progress: which lessons were started and completed.
  • Basic device info: your device's platform (e.g. Android), locale (e.g. "en"), and the app's version number.

We do not collect your name, email address, contacts, location, photos, or anything from other apps. We do not use advertising or tracking SDKs, and there are no ads in this app.

How it's sent and stored

Once a day's worth of gameplay is finished, the app sends that day's rows in a single request to a server we operate on Amazon Web Services (AWS). The request is signed so that only the app itself can submit valid data. If the request fails, nothing is lost — it tries again the next time the app is opened.

The data we receive is stored in private cloud storage that only we can access. We do not sell it, share it with third parties, or use it for advertising. It is used solely to understand how the game is played so we can improve it.

Standard network infrastructure (such as our cloud provider) may briefly log connection metadata like IP addresses as a normal part of handling any internet request. We do not use this for any purpose and do not retain it beyond what our infrastructure provider keeps by default for operational logs.

Your choices

You can turn this off in the app under Settings, Privacy, "Share gameplay stats". When it is off, no gameplay data is recorded or sent. It is on by default.

You can also ask us to delete the data we hold for your install. Email us (below) with the ID shown on that same Settings row, which is the only way we can tell which data is yours.

Children's privacy

This app is not directed at children and does not knowingly collect data from children. It contains no chat, no user-generated content, and no way to contact other players.

Changes to this policy

If this policy changes, we will update this page and the "Last updated" date above.
